## 📋 WHAT THIS REPOSITORY DOES

A **browser-based, local-first, non-jamming** defensive evidence and privacy registry for recording observable events involving:

- Bluetooth observations
- RF-related observations  
- Infrared observations
- Vibration/audio observations
- Mobile devices
- Drones
- And other possible technical incidents

## ✅ WHAT IT DOES (Defensive Protection)

✅ **Records timestamped observations** with event classification and optional technical reference
✅ **Computes SHA-256 integrity hash** for every record (Web Crypto API)
✅ **Stores everything ONLY in your browser** (localStorage) - **Nothing is uploaded to any server**
✅ **Exports full registry as JSON** for independent review
✅ **Allows deletion** of all local evidence at any time
✅ **Optionally reads Bluetooth device names** you voluntarily expose via Web Bluetooth
✅ **Reports which browser sensor APIs are available** (capability report only - nothing activated silently)

## ❌ WHAT IT DOES NOT DO (Ethical Boundaries)

❌ **No jamming** of any signals or equipment
❌ **No interference** with any devices
❌ **No hacking** or remote control
❌ **No hidden microphones** or cameras
❌ **No automatic transmission** of data
❌ **No RF jamming** capabilities
❌ **No surveillance** without explicit user action
❌ **No nationality requirements** - Protects ALL humans worldwide
