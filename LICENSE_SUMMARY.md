💰 ENTERPRISE PRICING

### Pricing Structure

The Enterprise License employs **value-based pricing** with the following options:

| Model | Description | Best For |
|-------|-------------|----------|
| **Per-Institution** | Flat annual fee | Single-location organizations |
| **Per-Student/Per-User** | Scalable based on count | Educational institutions |
| **Site-License** | Unlimited use at one location | Multi-user single site |
| **Enterprise-Wide** | Unlimited use across all locations | Large organizations |
| **Value-Based** | Custom pricing based on revenue/benefit | High-value use cases |

### Pricing Factors

Enterprise License fees are determined based on:

- **Organization Type** (Private School, Corporation, Business)

- **Scope of Use** (Internal, integration, redistribution)
